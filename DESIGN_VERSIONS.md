# 🎨 Laniameda Homepage Design Versions

Three radically different creative approaches for your AI creative studio website. Each version pushes design boundaries while maintaining your space-tech aesthetic.

---

## 🎬 Version 1: CINEMATIC FULLSCREEN
**Route:** `/1`
**Philosophy:** Editorial Immersion

### Design Concept
Magazine-style, full-bleed imagery with dramatic typography. Each portfolio piece takes the entire viewport with parallax scrolling and seamless transitions. Think Vogue meets Blade Runner.

### Key Features
- ✨ **Full-viewport portfolio slides** - Each project fills the screen
- 🎭 **Dramatic typography** - Massive headlines using Archivo (ultra-thin weight)
- 📸 **Image-first storytelling** - High-quality Unsplash imagery with gradient overlays
- 📊 **Data visualization** - Project stats displayed as large metrics
- 🎚️ **Vertical section indicator** - Minimalist navigation dots
- 🔄 **Smooth transitions** - 1.2s ease-out animations between sections
- 🎨 **Mix-blend-difference** nav - Navigation inverts over any background

### Typography
- **Display:** Archivo (100, 200, 300 weights)
- **Accent:** All-caps, wide letter-spacing (0.3em)
- **Hierarchy:** Scale from 3rem to 16rem

### Color Palette
- Black base (#000000)
- Cyan accents (#06B6D4)
- White/40% for secondary text
- Gradient overlays for depth

### Best For
- Fashion-forward brands
- Luxury positioning
- Portfolio-heavy showcase
- Cinematic storytelling

## ⚡ Version 2: EXPERIMENTAL GRID
**Route:** `/2`
**Philosophy:** Broken Symmetry

### Design Concept
Dynamic asymmetric grid with diagonal flow and unexpected layouts. Projects arranged in varying sizes with animated reveals and text breaking grid boundaries. Swiss brutalism meets cyberpunk.

### Key Features
- 🎯 **Custom cursor** - Spring physics cursor with mix-blend-difference
- 📐 **Asymmetric grid** - 2/3 + 1/3, 1/3 + 1/3 + 1/3, full-width layouts
- 🎨 **Bold typography** - Bebas Neue for massive headings
- 🌈 **Gradient accents** - Color-coded projects (purple, cyan, orange, green)
- 🔄 **Scale animations** - Hover scales to 0.98 for tactile feedback
- 📱 **Diagonal flow** - Alternating left/right content reveals
- 🎭 **Numbered sections** - Giant dimmed numbers (01-04) for capabilities

### Typography
- **Display:** Bebas Neue (ultra-condensed)
- **Body:** Space Grotesk (300, 700, 900 weights)
- **Scale:** Up to 20rem for hero text

### Color Palette
- Black base (#000000)
- Multi-color gradients per project
- Cyan primary (#06B6D4)
- Purple, orange, green accents

### Best For
- Bold, confident brands
- Design-forward positioning
- Interactive experiences
- Youth/tech audiences

---

## 🖥️ Version 3: 3D SPATIAL INTERFACE
**Route:** `/3`
**Philosophy:** Holographic Terminal

### Design Concept
Depth-based UI with 3D transforms and terminal aesthetics. Projects as holographic panels floating in space with glitch effects, scan lines, and hacker terminal vibes. Matrix meets Tron.

### Key Features
- 🖥️ **Terminal UI** - Command-line aesthetics with typewriter effects
- 🎭 **Glitch animations** - Text glitching with RGB split
- 📐 **3D perspective transforms** - Cards rotate based on mouse position
- 🌐 **Grid background** - Perspective grid recedes into distance
- 📺 **Scanlines overlay** - CRT monitor effect at 10% opacity
- ⏰ **Live system time** - Real-time clock in header
- 🎨 **Color-coded status** - Green/cyan/purple/orange for different states
- 🔲 **Corner brackets** - Cyberpunk UI chrome on cards

### Typography
- **Monospace:** JetBrains Mono (400, 700 weights)
- **Terminal syntax:** Cyan prompts, green output, purple paths
- **File names:** PROJECT_NAME.exe style

### Color Palette
- Black base (#000000)
- Matrix green (#00FF00) - primary
- Cyan (#00FFFF) - accents
- Magenta (#FF00FF) - glitch effect
- Orange/purple for status indicators

### Best For
- Tech-forward brands
- Developer tools
- Cyberpunk aesthetic
- Hacker/startup culture

## 🚀 Implementation Details

All versions are:
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ TypeScript-typed with Next.js App Router
- ✅ Framer Motion animations
- ✅ Production-ready code
- ✅ Real Cal.com booking integration
- ✅ Built and tested successfully

### Shared Components Used
- None - each version is completely standalone
- All use Google Fonts for unique typography
- All use Unsplash for high-quality imagery

### Performance Notes
- **V1:** Lightest - simple CSS transforms
- **V2:** Medium - custom cursor adds overhead
- **V3:** Heaviest - 3D transforms + glitch effects

## 💡 Design Philosophy

Each version avoids "AI slop" aesthetics by:
- **Distinctive typography** - No Inter, no Roboto
- **Bold creative choices** - Not playing it safe
- **Contextual design** - Matches creative studio positioning
- **Production quality** - Polished, refined details
- **Memorable moments** - Something users will remember

The goal: Make people think "Wow, these folks can *design*."
