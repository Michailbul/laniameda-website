# Laniameda — Skill Downloads

This folder serves packaged `.skill.zip` files via Vercel static hosting at
`https://laniameda.space/skills/<filename>.skill.zip`.

## Add a new skill

1. Build the skill folder locally (with its `SKILL.md` and any assets).
2. Zip it: `zip -r my-skill.skill.zip my-skill/`
3. Drop the resulting `.skill.zip` here, with a stable filename.
4. Reference it from the tutorial page, e.g.
   `<a href="/skills/my-skill.skill.zip" download>...`
